SQL / PL-SQL Diseño Relacional
S
Situación
Situation

Los técnicos de soporte perdían tiempo crítico navegando sistemas inconexos para resolver incidentes, sin una fuente centralizada de verdad técnica.

Support technicians were losing critical time navigating disconnected systems to resolve incidents, with no centralized source of technical truth.

T
Tarea
Task

Diseñar una solución que centralizara el conocimiento técnico y optimizara el proceso de escalamiento, impactando directamente el MTTR.

Design a solution to centralize technical knowledge and optimize the escalation process, directly impacting MTTR (Mean Time To Resolve).

A
Acción
Action

Diseñé la arquitectura relacional en SQL/PL-SQL, estructuré la lógica de navegación interna y apliqué principios de seguridad mediante roles y permisos de acceso por perfil de usuario.

Designed the relational architecture in SQL/PL-SQL, structured the internal navigation logic, and applied security principles through role-based access control per user profile.

R
Resultado
Result

Aplicación funcional con base de datos operativa que reduce el tiempo de búsqueda de información técnica y acelera el escalamiento correcto de incidentes, disminuyendo el MTTR.

Functional application with a live database that reduces technical information search time and accelerates correct incident escalation, reducing MTTR.
